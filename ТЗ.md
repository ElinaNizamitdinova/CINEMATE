# Техническое задание проекта CINEMATE

## 1. Общая информация

Название проекта: CINEMATE.

Тема: Каталог фильмов и сериалов (вариант № 21).

Тип проекта: веб-сайт для просмотра информации
о фильмах и сериалах.

Цель проекта: разработать удобный каталог,
в котором пользователь сможет знакомиться
с фильмами и сериалами, изучать их характеристики,
ставить оценки и формировать список
«Посмотреть позже».

## 2. Структура сайта

### 2.1. Главная страница (index.html)

Содержит:
- логотип и навигационное меню;
- описание проекта;
- подборку из 5–6 фильмов;
- постеры и краткую информацию;
- ссылки на подробные страницы.

### 2.2. Каталог (catalog.html)

Содержит:
- полный перечень фильмов и сериалов;
- не менее 12 позиций;
- изображения, названия и годы выпуска;
- элементы поиска, фильтрации и сортировки.

### 2.3. Страница фильма (movie.html)

Содержит:
- постер фильма;
- название и год выпуска;
- жанр и продолжительность;
- рейтинг;
- подробное описание;
- кнопку добавления в список
  «Посмотреть позже».

### 2.4. Список «Посмотреть позже» (watchlist.html)

Содержит:
- список отложенных фильмов;
- постеры и названия;
- демонстрационные отметки;
- элементы управления списком.

### 2.5. Контакты (contacts.html)

Содержит:
- контактную информацию;
- адрес и телефон;
- режим работы;
- слоган проекта;
- форму обратной связи.

## 3. Дизайн и оформление

- Светлая минималистичная цветовая гамма.
- Единый стиль всех страниц.
- Адаптивная верстка.
- Удобная навигация.
- Использование Flexbox и Grid.
- Отдельный файл CSS для оформления.

## 4. Технологии

- HTML5;
- CSS3;
- Visual Studio Code.

## 5. Дальнейшее развитие

В следующих практических работах планируется:
- добавление интерактивности на JavaScript;
- подключение внешнего API;
- разработка серверной части на Python;
- создание базы данных SQLite;
- регистрация и авторизация пользователей;
- публикация сайта в интернете.
