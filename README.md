# CINEMATE

Веб-каталог фильмов и сериалов.

## Информация о проекте

- Дисциплина: Введение в интернет-технологии
- Вариант: 21
- Практическая работа: № 1
- Технологии: HTML5, CSS3

## Структура проекта

- `index.html` — главная страница
- `catalog.html` — каталог фильмов и сериалов
- `movie.html` — страница с подробной информацией о фильме
- `watchlist.html` — список «Посмотреть позже»
- `contacts.html` — контактная информация и форма обратной связи
- `css/style.css` — общие стили сайта
- `images/` — изображения проекта

## Запуск

Откройте файл `index.html` в браузере.
